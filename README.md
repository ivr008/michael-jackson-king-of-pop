# Michael Jackson — The King of Pop 🎤

A detailed fan tribute: his life story, a career-spanning timeline (1958–2009), a photo gallery
through the years, famous concerts & tours, discography, records, quotes and legacy.

## Run locally
Open `index.html`, or:

```bash
python3 -m http.server 8000
```

## Build
`index.html` is generated by `build.py` from image metadata in `images.json`:

```bash
python3 build.py
```

## Images
Photographs come from Wikimedia Commons under their respective licences (many public domain);
full credits are listed in the collapsible "Image credits" section at the bottom of the page.

Fan-made, for informational/educational purposes. Not affiliated with the Jackson estate.
